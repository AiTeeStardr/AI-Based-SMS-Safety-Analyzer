# 🛡️ SMS Guard AI — ตรวจจับข้อความมิจฉาชีพและ SMS หลอกลวง
### โครงงานการเรียนรู้ของเครื่องและการประมวลผลภาษาธรรมชาติ (NLP & Supervised Learning)

🌐 **เว็บไซต์ (GitHub Pages):** [https://aiteestardr.github.io/AI-Based-SMS-Safety-Analyzer/](https://aiteestardr.github.io/AI-Based-SMS-Safety-Analyzer/)
📑 **เล่มรายงานฉบับเต็ม:** [PROJECT_REPORT.md](PROJECT_REPORT.md)

วางข้อความ SMS หรือแชตที่สงสัย แล้วระบบจะบอกระดับความเสี่ยง ไฮไลต์คำและลิงก์ที่น่าสงสัย พร้อมกราฟแสดงว่าแต่ละจุดเพิ่มหรือลดคะแนนไปเท่าไร ทำงานในเบราว์เซอร์ทั้งหมด ข้อความไม่ถูกส่งไปที่ใด ประวัติการตรวจเก็บในเครื่องของผู้ใช้เท่านั้น

---

## 🖥️ หน้าเว็บ

| หน้า | ไฟล์ | หน้าที่ |
|---|---|---|
| หน้าแรก | `index.html` | แนะนำระบบ และทางลัดไปแต่ละหน้า |
| ตรวจสอบ SMS | `check.html` | วางข้อความ หรือเลือกข้อความตัวอย่าง แล้วกดเริ่มวิเคราะห์ |
| ผลการวิเคราะห์ | `result.html` | มาตรวัดความเสี่ยง คำสำคัญ ข้อความต้นฉบับที่ไฮไลต์ กราฟที่มาของคะแนน เหตุผล และคำแนะนำ |
| ประวัติ | `history.html` | ย้อนดูผลที่เคยตรวจ กรองตามผล ช่วงเวลา และค้นหาข้อความ |
| ข้อมูลโมเดล | `model.html` | ผลทดสอบโมเดล NLP และองค์ประกอบชุดข้อมูล (อ่านจากไฟล์ CSV) |

รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์ มีโหมดตัวหนังสือใหญ่สำหรับผู้สูงอายุ (ปุ่ม "ก+" มุมขวาบน)

## 🐍 Backend (Python)

เว็บทำงานคู่กับ **Python backend** (`server.py`) ที่เสิร์ฟหน้าเว็บ และให้ REST API สำหรับโมเดล ML

| Endpoint | หน้าที่ |
|---|---|
| `POST /api/analyze` | รับ `{"text": "..."}` คืนความน่าจะเป็นที่เป็นมิจฉาชีพจากโมเดล scikit-learn พร้อม n-gram ที่ส่งผลมากที่สุด |
| `GET /api/metrics` | ผลทดสอบโมเดล (`model/metrics.json`) |
| `GET /api/health` | สถานะเซิร์ฟเวอร์และโมเดล |

```
เบราว์เซอร์ ──POST /api/analyze──▶ server.py ──▶ model/scam_model.joblib (TF-IDF char n-gram + Logistic Regression)
     │
     └─ ระบบกฎ + กราฟคะแนน (js/engine.js) ทำงานในเบราว์เซอร์ → ผลหลัก อธิบายเหตุผลได้
```

- **ผลหลัก** มาจากระบบกฎ (อธิบายได้ว่าคะแนนมาจากไหน) ส่วนโมเดล ML แสดงเป็น "ความเห็นที่สอง" และบอกเมื่อผลต่างกัน
- ถ้าไม่มี Python backend (เช่นเปิดผ่าน GitHub Pages) เว็บยังทำงานได้ด้วยระบบกฎอย่างเดียว

## 📁 ไฟล์สำคัญในโปรเจกต์นี้

1. **`css/app.css`**: ธีมโทนดำ-แดงและสไตล์ร่วมของทุกหน้า
2. **`js/engine.js`**: ระบบกฎตรวจจับ (ฟังก์ชัน `SG.analyze`) พร้อมรายชื่อโดเมนทางการ
3. **`js/shared.js`**: เมนู ไอคอน ที่เก็บประวัติ และตัววาดกราฟ/มาตรวัด
4. **`server.py`**: Python backend (เสิร์ฟเว็บ + REST API โหลดโมเดลมาทำนาย)
5. **`train_model.py`**: ฝึกและเปรียบเทียบโมเดล 4 ตัว ตัดข้อความซ้ำ ใช้ character n-gram แล้วบันทึก `model/scam_model.joblib` และ `model/metrics.json`
6. **`external_check.csv`**: ข้อความ 15 ข้อความนอกชุดข้อมูลสำหรับทดสอบความเป็นจริง
7. **`scam_detection_pipeline.py`**: สคริปต์เดิม (เก็บไว้อ้างอิง ไม่ได้ตัดข้อความซ้ำ จึงได้ 100% เกินจริง)
8. **`Scam_SMS_Detection_Project.ipynb`**: Jupyter Notebook พร้อมคำอธิบาย เปิดใน VS Code หรือ Google Colab ได้
9. **`thai_scam_sms_dataset.csv`**: ชุดข้อมูลข้อความภาษาไทย 700 รายการ (ข้อความไม่ซ้ำ 399 รายการ)
10. **`scam_model_evaluation.csv`**: ตารางผลทดสอบแบบเดิม (ก่อนตัดซ้ำ)
11. **โฟลเดอร์ `charts/`**: ภาพกราฟจากสคริปต์เดิม

## ⚠️ ข้อจำกัดที่ควรรู้

- ชุดข้อมูลเดิม 700 รายการมีข้อความซ้ำ 301 รายการ หลังตัดซ้ำเหลือ 399 ข้อความ ผลบนชุดทดสอบยังได้ ~100% แต่กับข้อความนอกชุดข้อมูล 15 ข้อความโมเดลทายถูก 11/15 (เตือนผิดกับข้อความจริงบางแบบ) จึงใช้ระบบกฎเป็นผลหลัก ควรเก็บ SMS จริงเพิ่มแล้วฝึกใหม่
- ระบบกฎครอบคลุมเฉพาะรูปแบบที่ระบุไว้ ข้อความรูปแบบใหม่อาจตรวจไม่พบ ผลการตรวจเป็นการประเมิน ไม่ใช่การรับรอง
- สงสัยว่าถูกหลอก โทรสายด่วนศูนย์ปราบปรามอาชญากรรมทางเทคโนโลยี **1441** ฟรี 24 ชั่วโมง
